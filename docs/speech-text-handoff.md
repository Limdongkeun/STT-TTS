# 소리용 답(speechText) 만들기 — LLM 담당 전달 문서

> 2026-11-19 · STT-TTS(가족비서 음성) → 텍스트 채팅(답 만드는 LLM) 담당.
> TTS는 ElevenLabs로 운영하고, 모델 자체는 학습시키지 않는다. 자연스럽게 들리게 하는 일은 **답을 만드는 쪽이 '소리용 글'을 잘 쓰는 것**이 가장 크다. 이 문서는 그 약속(모양·규칙·예시)이다.
> 자세한 규칙과 시험 답 34개의 실제 예: `docs/speech-style-guide.md`.

## 1. 답 하나에 글 두 벌

```json
{
  "answerText": "가스비 4만 2천 원은 아내가 11월 5일에 낸 걸로 기록했어요.",
  "speechText": "네, 가스비는 아내가 냈다고 적어 뒀어요."
}
```

- `answerText`: 화면에 보이는 답. 금액·날짜·시각을 정확하게 다 쓴다.
- `speechText`: 스피커로 읽는 말. 가족에게 말하듯 짧은 입말로 쓴다. 없으면 서버가 `answerText`를 간단히 다듬어 읽지만(안전망) 훨씬 어색하다.
- 스트리밍이 되면 `speechText`를 먼저, 문장이 끝날 때마다 보내 준다. 첫 문장이 끝나자마자 TTS를 시작해서 첫 소리가 빨라진다.

## 2. speechText 규칙

1. **한 문장은 25자 안팎.** 길면 두 문장으로 나눈다. 첫 문장이 짧을수록 소리가 빨리 난다.
2. **물은 것의 답을 첫 문장에.** "얼마 남았어?"에는 남은 돈부터 말한다.
3. **기록·변경을 했으면 "네," "알겠어요." "좋아요,"로 시작한다.** 매번 같은 말로 시작하지 않는다. 이미 한 일은 과거형으로 쓴다("적어 둘게요" 말고 "적어 뒀어요").
4. **"아," "음," 같은 감탄사로 시작하지 않는다.** (11/18 시험 메모: C5 "아, 두 시로…"가 어색함)
5. **사람 이름·호칭으로 문장을 시작하지 않는다.** "아버지 다음 진료는…"은 "아버지!" 하고 부르는 말투로 읽힌다. 날짜나 일을 앞에 두거나("십이일 목요일 오전 열 시에 아버지 진료가 있어요"), 조사를 붙인다("소윤이는"). (11/17 C6, 11/18 E2 메모)
6. **숫자는 말하듯 쓴다.** 2시 30분 → 두 시 반, 오후 9시 → 밤 아홉 시, 4만 2천 원 → 사만 이천 원. 같은 달 날짜는 달을 빼고, 가까운 날은 내일·다음 주로 쓴다. 1·11·21·31일은 "일 일", "이십일 일"처럼 띄운다.
7. **글말을 쓰지 않는다.** '기록했어요', '등록된', '1건', '확인돼요', '시험 기록에', 따옴표는 쓰지 않는다.
8. **숨 쉴 곳에 쉼표.** '~인데요,' '~고요,' 뒤에 쉼표를 둔다. 쉼표가 TTS의 쉼이 된다.
9. **금액·날짜가 셋 넘게 이어지면 줄인다.** 정확한 값은 `answerText`에 있으니 소리에서는 덜 중요한 것을 뺀다.
10. **사실은 반드시 `answerText`와 같게.** 금액·날짜·사람·했다/안 했다를 바꾸지 않는다. 틀리게 말하느니 줄인다.
11. **말투는 존댓말, 끝은 부드럽게.** "~예요/~어요"로 맺고, "~습니다"는 쓰지 않는다.
12. **소리가 비슷해 헷갈리는 낱말은 풀어 쓴다.** '하원'은 '학원'과 구분이 안 들린다(11/19 청취) → '데리러 가기', '어린이집 끝나는 시간'. '등원' → '어린이집 보내기'.
13. **숫자 '1'은 천·백 앞에서 빼고 쓴다.** '1천 원'이 아니라 '천 원'(서버도 고치지만 처음부터 그렇게 쓴다).
14. **모를 때:** "음, 그건 아직 잘 모르겠어요. 한 번만 다시 말해 줄래요?" 대신, 무엇을 몰랐는지 짧게 되묻는다(예: "어떤 약을 말씀하시는 거예요?").

## 3. LLM 지시문에 붙일 것 (복사해서 쓰기)

```text
답을 두 가지로 만들어 JSON으로 돌려줘: {"answerText": ..., "speechText": ...}
- answerText: 화면에 보일 답. 금액·날짜·시각을 정확하게.
- speechText: 스피커로 읽어 줄 말. 가족에게 말하듯 짧은 입말로.
  1) 한 문장은 25자 안팎. 길면 두 문장으로 나눠.
  2) 물은 것의 답을 첫 문장에.
  3) 기록·변경을 했으면 "네," "알겠어요." "좋아요," 중 하나로 시작해. 매번 같은 말로 시작하지 마.
  4) "아," "음," 같은 감탄사나 사람 이름·호칭으로 문장을 시작하지 마. 이름은 조사를 붙이거나 문장 가운데에 둬.
  5) 숫자는 말하듯: 2시 30분 → 두 시 반, 오후 9시 → 밤 아홉 시, 4만 2천 원 → 사만 이천 원. 같은 달 날짜는 달을 빼고, 가까운 날은 내일·다음 주로.
  6) "기록했어요" "등록된" "1건" "확인돼요" 같은 글말, 따옴표는 쓰지 마.
  7) 숨 쉴 곳에 쉼표(…인데요, …고요,).
  8) 금액·날짜가 셋 넘게 이어지면 덜 중요한 것은 줄여(정확한 값은 answerText에 있음).
  9) 금액·날짜·사람·했다/안 했다는 answerText와 반드시 같게. 틀리게 말하느니 줄여.
  10) "~예요/~어요"로 부드럽게 맺어. "~습니다"는 쓰지 마.
  11) '하원'·'등원'처럼 소리가 비슷한 말과 헷갈리는 낱말은 풀어 써: '데리러 가기', '어린이집 끝나는 시간', '어린이집 보내기'.
```

## 4. 예시 (시험 답에서)

| 물은 말 | 화면 답(answerText) | 소리 답(speechText) |
|---|---|---|
| 30분 전에 먹였어 | 시험 기록에 11월 5일 오후 2시 30분에 먹인 걸로 기록했어요. 가상 일정에 등록된 다음 복용 예정 시각은 오후 9시예요. | 네, 두 시 반으로 적어 뒀어요. 다음 약은 밤 아홉 시예요. |
| 아니, 한 시간 전이야 | …오후 2시에 먹인 걸로 수정했어요… | 두 시로 고쳐 뒀어요. 다음 약은 그대로 밤 아홉 시예요. |
| 아버지 혈압약 떨어졌는데 다음 병원 언제야? | 아버지 다음 진료는 11월 12일 목요일 오전 10시예요. 혈압약 처방은 그때 받으면 돼요. | 십이일 목요일 오전 열 시에 아버지 진료가 있어요. 혈압약은 그때 처방받으면 돼요. |
| 소윤이 이번 주 학교 학원 일정 뭐야? | 소윤이는 수요일에 학교 체험학습, 금요일에 피아노 학원이 있어요. | 소윤이는 수요일에 체험학습 가고요, 금요일엔 피아노 학원 가요. |
| 가스비 얼마 내야 돼? | 가스비 4만 2천 원은 아직 안 냈어요. 11월 25일까지 내야 해요. | 가스비 사만 이천 원은 아직 안 냈어요. 이십오일까지 내면 돼요. |

## 5. TTS 쪽에서 하는 것 (STT-TTS 담당)

- **엔진:** ElevenLabs v4 Turbo, 목소리 여자 Anna Kim·남자 Chris, 설정 '차분하게'(stability 0.65, speed 0.95 — 11/19 사용자가 견본 4가지 중 고름). 서버(8002)가 `speechText`를 받아 숫자를 한 번 더 입말로 바꾸고(안전망) 읽는다.
- **한 번에 읽기:** ElevenLabs는 답 전체(speechText)를 한 번에 보내 읽는다(앱이 문장마다 나누는 건 107 TTS 때만). 그래서 문장 사이 억양은 ElevenLabs가 이어 준다. 억양·쉼은 글의 문장부호(쉼표·마침표·물음표)와 문장 길이로 정해지니, 2장 규칙대로 쓰는 게 곧 억양을 다듬는 일이다.
- **발음:** 11/19 견본에서 소윤이·콩이·심장사상충·체험학습·'일 일'은 모두 바르게 읽혔다. 이상하게 읽히는 낱말이 나오면 서버에서 읽기 전에 바꿔 주는 발음 목록에 더한다.
- **자주 나오는 답은 미리 만들어 둔다:** 인사, "적어 뒀어요" 같은 짧은 답은 소리를 미리 만들어 두고 다시 쓴다(크레딧·기다림 줄이기).
- ElevenLabs로 만든 소리는 다른 모델 학습에 쓰지 않는다(ElevenLabs 정책).

## 6. 같이 다듬는 방법

- 폰 시험에서 '들림 ×'나 메모가 붙은 답을 STT-TTS 쪽이 모아 이 문서 4장 예시와 2장 규칙에 더한다.
- 답 만드는 쪽은 바뀐 규칙·예시를 LLM 지시문에 그대로 반영한다(예시는 5~10개만 골라 넣는다).
