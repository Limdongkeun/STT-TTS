## B. 답 문장 (TTS 시험 — 읽기 변환 후 듣기)

| # | 화면용 글 | 기대 읽기 |
|---|---|---|
| B1 | 내일 일정은 2개예요. | 내일 일정은 두 개예요. |
| B2 | 오후 3시 30분에 외할머니 병원 예약이 있어요. | 오후 세 시 삼십 분에 … |
| B3 | 저녁 7시 가족 식사에 4명이 와요. | 일곱 시, 네 명 |
| B4 | 11월 4일 화요일이에요. | 십일월 사일 |
| B5 | 6월 10일에 할아버지 생신이에요. | 유월 십일 |
| B6 | 10월 관리비는 12,000원 늘었어요. | 시월, 만 이천원 |
| B7 | 이번 달 생활비는 3.8억 원이 아니라 380만 원이에요. | 삼억 팔천만 원, 삼백팔십만 원 |
| B8 | 병원 전화번호는 02-123-4567이에요. | 공이 일이삼 사오육칠 |
| B9 | 2시간 뒤에 다시 알려 드릴게요. | 두 시간 |
| B10 | 12시에 점심, 15시에 회의가 있어요. | 열두 시, 십오 시 |
| B11 | AI 가족비서가 형에게 부탁 카드를 보냈어요. | 에이아이 |
| B12 | 지민이 학원은 4시~6시예요. | 네 시에서 여섯 시 |
| B13 | 엄마가 아침 약을 드셨어요. 오늘도 수고하셨어요! | 문장 끝 억양 |
| B14 | 아빠는 수락했고, 형은 아직 답이 없어요. | 쉼표 끊어 읽기 |
| B15 | 외할머니, 외삼촌, 지민이, 서연이가 와요. | 이름 여러 개 |

> B 문장은 `/tts` 에 `"normalize": true` 로 넣으면 서버가 읽기용으로 바꾼 뒤 읽는다.
> 읽기 변환이 기대와 다르면 `server/app/normalize.py` 규칙과 `server/tests/test_normalize.py` 에 사례를 더한다.

## C. 부부 공유 업무 문장 (STT·답·읽기 함께 시험)

기대 답과 시험 데이터는 [.scratch/family-shared-tasks/spec.md](../.scratch/family-shared-tasks/spec.md)에 있다. 앱에서 **시험 데이터 초기화**를 누른 뒤 위에서부터 차례로 말한다. 누가 했는지는 문장 속 **남편·아내**로 알아듣는다(앱에서 '나'를 고르지 않음). 기록을 바꾸는 말은 "아내가 …했어", "…했다고 체크해줘"처럼 말한다("내가"만 쓰면 아내로 본다).

| # | 문장 | 보는 점 |
|---|---|---|
| D1 | 장보기 목록 뭐 남았어? | 목록 묻기, "2가지" 읽기 |
| D2 | 우유랑 기저귀 장보기 목록에 넣어줘 | 여러 물건 넣기 |
| D3 | 기저귀는 아내가 샀어 | 목록에서 빼기 |
| D4 | 이번 달 관리비 냈어? | 금액 읽기(23만 4천 원) |
| D5 | 가스비 얼마 내야 돼? | 금액·마감일 |
| D6 | 가스비 아내가 냈어 | 납부 기록 |
| D7 | 이번 달 생활비 얼마 남았어? | 큰 금액(150만 원) |
| D8 | 오늘 마트에서 8만 4천 원 썼어 | STT가 금액을 숫자로 적는지 |
| D9 | 내일 어린이집 하원 누가 가? | 날짜·요일 |
| D10 | 목요일 하원은 아내가 가는 걸로 바꿔줘 | 당번 바꾸기 |
