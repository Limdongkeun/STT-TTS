# 공유 작업판 (Claude · Codex)

Claude와 Codex가 이 파일 하나로 일을 이어받는다. 규칙은 `AGENTS.md`의 "공유 작업판" 절을 따른다.

- **시작 전**: 이 파일을 끝까지 읽는다. 특히 "진행 중"과 최근 "작업 기록"을 본다.
- **작업을 잡을 때**: "진행 중"에 `누가 · 무엇 · 시작 시각 · 건드리는 파일`을 적는다. 다른 쪽이 잡은 파일은 건드리지 않는다.
- **끝나면**: "진행 중"에서 그 줄을 지운다. "작업 기록" 맨 위에 한 줄을 더하고, 바뀐 상태가 있으면 다른 칸도 고친다.
- 시각은 KST, 날짜는 `YYYY-MM-DD`로 적는다. 비밀값(키·토큰·주소 비밀번호)은 적지 않는다.

- **서버 STT 힌트 없이(2026-11-17 사용자)**: Qwen 한국어판은 힌트를 넣지 않는다. 11/13 33개에서 힌트 42는 핵심어 +2(D7 사업비→생활비, C3 부루펜→부르펜)지만 CER 0.098→0.104, 힌트 글 받아 적기 사고(D19), 시험표 낱말 치우침. 낱말은 STT 추가 학습으로 익힌다(학습 뒤 D7·C3 따로 확인). 서버 힌트 코드는 지웠고 필요하면 git(9239dc0)에서 되살린다
- **버튼 말하기는 정확도(서버 Qwen), 대화 모드는 속도(폰 STT·미리 답)로 나눈다.** Qwen은 지금은 맥에서 돌리며 정확도를 높이고, 나중에 107(회사 서버) GPU로 옮길지 정한다. (2026-11-16 사용자)
- **서버 실행·종료는 사용자가 직접 처리한다. AI는 명시적으로 요청받은 경우에만 서버를 켜거나 끈다.** (2026-11-05 사용자 지시)

- 임시 TTS 기본은 prerecorded(지수 로컬 WAV)다. 2026-11-12 사용자 결정으로 입말 문장 34개+모르는 질문 답을 사용자 키로 다시 녹음했다(`output/audio/jisoo-spoken`, 예전 c1-c7·d1-d25·zip 삭제). 문장이 일치할 때만 재생하고 불일치하면 안내를 보낸다. ElevenLabs API는 사용자가 그때그때 허락할 때만 쓴다(입말 문장을 고치면 다시 녹음해야 하니 먼저 묻는다).

- **서버는 하나(8002, `.venv-asr`)로 띄우고 앱 버튼으로 STT·TTS를 고른다.** TTS를 107·지수 녹음으로 쓰면서 맥에서 TTS 모델을 돌리지 않게 돼 패키지 충돌이 없어졌다. 힌트 켜고 끄기 버튼은 넣지 않는다(서버 `STT_HINTS`로만). (2026-11-09 사용자 결정)
