# 공유 작업판 (Claude · Codex)

Claude와 Codex가 이 파일 하나로 일을 이어받는다. 규칙은 `AGENTS.md`의 "공유 작업판" 절을 따른다.

- **시작 전**: 이 파일을 끝까지 읽는다. 특히 "진행 중"과 최근 "작업 기록"을 본다.
- **작업을 잡을 때**: "진행 중"에 `누가 · 무엇 · 시작 시각 · 건드리는 파일`을 적는다. 다른 쪽이 잡은 파일은 건드리지 않는다.
- **끝나면**: "진행 중"에서 그 줄을 지운다. "작업 기록" 맨 위에 한 줄을 더하고, 바뀐 상태가 있으면 다른 칸도 고친다.
- 시각은 KST, 날짜는 `YYYY-MM-DD`로 적는다. 비밀값(키·토큰·주소 비밀번호)은 적지 않는다.

## 정한 것

- **서버 실행·종료는 사용자가 직접 처리한다. AI는 명시적으로 요청받은 경우에만 서버를 켜거나 끈다.** (2026-11-05 사용자 지시)

- 임시 TTS 기본은 prerecorded(지수 C1~C7·D1~D25 로컬 WAV)다. 문장이 일치할 때만 재생하고 불일치하면 422 안내를 보낸다. ElevenLabs 추가 API 사용은 금지한다.

- **서버는 하나(8002, `.venv-asr`)로 띄우고 앱 버튼으로 STT·TTS를 고른다.** TTS를 107·지수 녹음으로 쓰면서 맥에서 TTS 모델을 돌리지 않게 돼 패키지 충돌이 없어졌다. 힌트 켜고 끄기 버튼은 넣지 않는다(서버 `STT_HINTS`로만). (2026-11-09 사용자 결정)
- (예전) 실제 STT 서버는 8001(`--extra asr`), 답+TTS 서버는 8002(`--extra tts`)로 나눈다. qwen-asr와 qwen-tts가 서로 다른 transformers 버전을 쓰기 때문이다. mock만 쓸 때는 8002 하나로 된다.
- 시험 문장에 맞춘 규칙 보정은 멈춘다. 뜻 이해는 모델로 풀고, 말바꿈 기준선(128문장)은 모델과 비교하려고 규칙을 고치지 않고 둔다. 고치는 것은 STT·재생·시간 재기처럼 어떤 문장에나 생기는 문제만. (2026-11-06 사용자와 정함)
- family-demo 답은 시험 시각 2026-11-05 15:00으로 고정한다(`DEMO_CLOCK=fixed` 기본). 녹음·기대 답이 그 날짜 기준이다. (2026-11-06)
- **이 프로젝트 범위는 STT → 서버 전달 → TTS다.** 서버의 답 만들기(LLM·DB)는 다른 담당이 한다. 여기서는 받은 답을 얼마나 자연스럽게 소리로 전하는지(TTS)에 집중한다. (2026-11-06 사용자 결정)
