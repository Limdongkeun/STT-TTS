# 소리용 문장 규칙 (가족비서 답을 TTS로 읽을 때)

가족비서는 답을 두 가지로 낸다. **화면 답**은 눈으로 읽는 글이고, **소리용 문장**은 TTS가 읽는 말이다. 이 문서는 소리용 문장을 쓰는 규칙이다. 답을 만드는 쪽(LLM·DB)에 넘기려고 쓴다.

## 왜 따로 쓰나

2026-11-09에 같은 목소리(107 Qwen3-TTS, G 목소리)로 같은 답을 두 가지로 읽혀 들어 봤다. 견본 목소리를 바꾼 것보다 **문장을 입말로 바꾼 쪽이 더 사람 같다**는 평가가 나왔다(D7, D11, D24). 화면 답("시험 기록에 … 기록했어요")을 그대로 읽으면 TTS도 글을 읽는 말투가 된다.

| 사례 | 화면 답 (그대로 읽으면 어색함) | 소리용 문장 (더 자연스러웠음) |
|---|---|---|
| D7 | 이번 달 생활비 150만 원 중 98만 원을 써서 52만 원 남았어요. | 이번 달 생활비는 오십이만 원 남았어요. 백오십만 원 중에 구십팔만 원 썼어요. |
| D11 | 이번 주 분리수거는 남편 차례예요. 아직 안 했어요. | 이번 주 분리수거는 남편 차례인데요, 아직 안 했어요. |
| D24 | 콩이 심장사상충 약은 매달 1일에 먹여요. 이번 달은 11월 1일에 남편이 먹였고, 다음은 12월 1일이에요. | 콩이 심장사상충 약은 매달 초에 먹여요. 이번 달 건 남편이 벌써 먹였고요, 다음은 십이월 일 일이에요. |

## 규칙

1. **한 문장은 짧게.** 25자 안팎. 길면 두 문장으로 나눈다. TTS가 문장마다 따로 만들어 첫 문장부터 틀기 때문에, 첫 문장이 짧을수록 소리가 빨리 난다.
2. **가장 궁금한 것을 먼저.** 물은 것의 답을 첫 문장에 둔다. 예: "얼마 남았어?" → 남은 돈을 먼저, 쓴 돈은 뒤에.
3. **기록·변경에는 맞장구로 시작.** "네," "알겠어요." "좋아요," "아," 같은 첫마디를 넣되, 매번 같은 말로 시작하지 않는다. 이미 한 일은 과거형으로 말한다("적어 둘게요" 말고 "적어 뒀어요"). 예: "네, 두 시 반으로 적어 뒀어요."
4. **말하듯 바꾼다.** '2시 30분' → '두 시 반', '오후 9시' → '밤 아홉 시', 같은 달 날짜는 '십일월'을 빼고 '이십일', 내일·다음 주처럼 가까운 날은 날짜 대신 그 말을 쓴다.
5. **글말을 뺀다.** '시험 기록에', '가상 일정에 등록된', '확인돼요', '~로 표시했어요', '1건' 같은 말은 '적어 둘게요', '하나 있어요'처럼 바꾼다. 따옴표('…')는 쓰지 않는다.
6. **숨 쉴 곳에 쉼표.** '~인데요,' '~고요,' 뒤에 쉼표를 둔다. 쉼표가 TTS의 쉼이 된다.
7. **숫자가 줄줄이 이어지지 않게.** 금액·날짜가 셋 넘게 이어지면 덜 중요한 것은 줄이거나("정기검사랑 남편 여권은 내년이에요") 화면에만 둔다.
8. **사실은 화면 답과 같아야 한다.** 금액, 날짜, 사람, 했다/안 했다는 바꾸지 않는다. 줄이는 것은 되지만 틀리게 말하면 안 된다. 정확한 시각·날짜가 꼭 필요하면 화면 답에 둔다.
9. **숫자는 한글로 써도 되고 아라비아 숫자로 써도 된다.** 서버가 읽기 전에 숫자를 한글로 바꾼다. 1·11·21·31일은 서버가 '일 일', '이십일 일'처럼 띄어 읽게 바꾼다(2026-11-12 청취에서 '일일'·'이릴'·'초하루'보다 자연스러웠음). 그 밖에 소리가 어색한 것은 직접 고쳐 쓴다.

## 넘길 때 모양 (LLM·DB 담당)

답 하나에 두 가지를 같이 준다. 지금 시험 서버의 `/ask` 응답이 이미 이 모양이다.

```json
{
  "answerText": "가스비 4만 2천 원은 아내가 11월 5일에 낸 걸로 기록했어요.",
  "speechText": "네, 가스비는 아내가 냈다고 적어 뒀어요."
}
```

- `answerText`: 화면에 보이는 답. 정확한 금액·날짜·시각을 다 담는다.
- `speechText`: TTS가 읽는 말. 위 규칙대로 쓴다. 없으면 화면 답을 읽는다(아래 '안전망'을 거쳐서).
- DB에서 정해진 틀로 만드는 답은 틀을 두 벌 둔다. 예: 화면 `"{항목} {금액}은 {사람}이 {날짜}에 냈어요."`, 소리 `"{항목}는 {사람}이 {날짜_말}에 냈어요."`
- 글을 흘려 보낼 수 있으면(스트리밍) `speechText`를 먼저, 문장 단위로 보내 준다. 첫 문장이 끝나는 대로 TTS를 시작해서 첫 소리가 빨라진다.

### LLM 지시문 예시

LLM에 넣을 지시문의 소리용 문장 부분 예시다. 답 만드는 쪽 지시문에 이어 붙인다.

```text
답을 두 가지로 만들어 JSON으로 돌려줘: {"answerText": ..., "speechText": ...}
- answerText: 화면에 보일 답. 금액·날짜·시각을 정확하게.
- speechText: 스피커로 읽어 줄 말. 가족에게 말하듯 짧은 입말로.
  1) 한 문장은 25자 안팎. 길면 두 문장으로 나눠.
  2) 물은 것의 답을 첫 문장에.
  3) 기록·변경을 했으면 "네," "알겠어요." "좋아요," 중 하나로 시작해(매번 같은 말로 시작하지 마).
  4) 숫자는 말하듯: 2시 30분 → 두 시 반, 오후 9시 → 밤 아홉 시. 같은 달 날짜는 달을 빼고, 내일·다음 주처럼 가까운 날은 그 말로.
  5) "기록했어요" "등록된" "1건" "확인돼요" 같은 글말, 따옴표는 쓰지 마.
  6) 숨 쉴 곳에 쉼표(…인데요, …고요,).
  7) 금액·날짜가 셋 넘게 이어지면 덜 중요한 것은 줄여서 말해(정확한 값은 answerText에 있음).
  8) 금액·날짜·사람·했다/안 했다는 answerText와 반드시 같게. 틀리게 말하느니 줄여.
```

### 서버 안전망 (speechText가 없거나 글말이 섞여 올 때)

시험 서버는 TTS로 보내기 전에 자주 나오는 글말만 바꾼다(`server/app/spoken_answers.py` `to_spoken_style`). 숫자·이름은 바꾸지 않고, 순서를 바꾸거나 줄이지도 않는다. 그래서 안전망이고, 자연스러운 입말은 위의 `speechText`로 받아야 한다.

| 글말 | 바꾼 말 |
|---|---|
| 이 질문에 맞는 시험 답변이 준비돼 있지 않아요. (답 전체) | 음, 그건 아직 잘 모르겠어요. 한 번만 다시 말해 줄래요? |
| 시험 기록에 | (뺌) |
| 가상 일정에 등록된 다음 복용 예정 시각은 | 다음 약은 |
| ~걸로 기록했어요 / ~을 기록했어요 | ~걸로 적어 뒀어요 / ~을 적어 뒀어요 |
| ~걸로 수정했어요 · 표시했어요 · 체크했어요 | ~걸로 고쳐 뒀어요 · 해 뒀어요 · 체크해 뒀어요 |
| 1건이에요 · 두 건이에요 | 하나예요 · 두 개예요 |
| 남편에게 · 아내에게 | 남편한테 · 아내한테 |
| 따옴표('…', "…") | (뺌) |

## 지금 시험 서버에서는

- 시험 답 34개의 소리용 문장을 `server/app/data/spoken_answers.json`에 넣어 두었다. 시험용 고정 답이라 손으로 썼다. 목록에 없는 답은 위 '서버 안전망' 규칙으로 다듬는다.
- 앱에서 TTS를 107 G 목소리(또는 맥 Qwen TTS)로 고를 때만 이 문장을 읽는다. 지수 사전 녹음은 녹음과 글이 같아야 해서 원래 문장을 읽는다.
- 끄려면 서버를 `SPOKEN_ANSWERS=off`로 켠다. 시험표 TTS 이름에 '· 입말'이 붙어서 원래 문장으로 읽은 저장본과 따로 비교된다.
