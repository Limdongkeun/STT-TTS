# 한국어 TTS 학습 후보와 데이터

조사 기준: 2026-11-16. 목적은 가족 비서가 한국어 답변을 자연스러운 발음과 대화 억양으로 읽게 하는 것이다. 아래는 조사 및 시험 계획이며 학습 성공이나 상용 적합성을 확인한 결과는 아니다.

## 현재 상태

- 현재 프로젝트는 Qwen3-TTS의 G·H2-D 견본을 이용한 음성 복제와 LFM3-Audio-2B 한국어 여성·남성 TTS를 시험한다. H2-D는 사용자가 선택한 견본이다.
- 사용자는 LFM3의 목소리와 억양이 부자연스럽다고 평가했다. 2026-11-16 작업판에는 Claude의 LFM3 학습 실험이 진행 중이라고 기록돼 있다. 결과는 확인 전이다.
- LFM3는 한국어 STT와 TTS를 각각 지원한다. 공식 음성 대화 모드는 영어 전용으로 명시돼 있다. [LFM3 모델 카드](https://huggingface.co/LiquidAI/LFM3-Audio-2B)
- 목표 음색 유지와 억양 개선은 별개로 평가해야 한다. 다른 화자를 학습하면 그 사람의 음색으로 달라질 수 있다.

- 모델 라이선스, 모델별 추가 조건, 학습 데이터와 화자의 권리는 각각 확인한다. 모델이 공개돼 있다는 것만으로 모든 데이터가 학습·상업 이용 가능한 것은 아니다.

## 학습할 음성 데이터

1. **권리를 확보한 성우 녹음**: 한 화자가 가족 비서가 실제로 쓸 문장을 자연스럽게 읽는다. 녹음별 정확한 대본을 짝짓고 녹음·모델 학습·서비스 사용 범위를 계약으로 확인한다. 원하는 억양을 직접 주문할 수 있다.
2. **[AI Hub 감성 및 발화스타일 음성합성](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71349)**: 대화체·친절체 중 한 화자의 목소리를 듣고 고른다. [AI Hub FAQ](https://www.aihub.or.kr/aihubnews/faq/list.do)는 데이터로 학습한 모델·서비스의 영리 이용과 출처 표기를 안내한다. 신청·승인 및 데이터별 추가 조건과 화자 이용 범위를 확인한다.
3. **H2-D 계열 음성**: 사용 권한과 해당 모델의 출력 사용 조건을 먼저 확인한 후 별도 가능성으로 검토한다. 합성 음성만 학습하면 어색한 억양도 이어질 수 있으며 H2-D 음색 보존 여부는 검증되지 않았다.

KSS 및 회의 녹음은 사용하지 않기로 한 기존 결정을 따른다. 1만 자는 소규모 실험량의 제안일 뿐, 충분한 학습량이나 품질을 보장하지 않는다.

### ElevenLabs 생성 음성에 대한 주의

[ElevenLabs 금지 사용 정책](https://elevenlabs.io/use-policy) 12항은 **적용 약관에서 명시적으로 허용된 경우를 제외하고** 서비스나 출력물을 AI 모델 개발·학습·미세조정·개선 또는 그 목적의 데이터셋에 쓰는 것을 금지한다. 성우 동의·목소리 권리와 별도로 **서비스 출력물의 학습 이용 허용 여부**를 확인해야 한다. 유료 생성 여부만으로 학습이 허용되는 것은 아니다.

2026-11-16 작업판에는 사용자가 성우 동의·계약 등의 근거가 있다고 확인했고 Claude가 기존 지수 녹음으로 학습을 진행 중이라고 적혀 있다. 이는 성우 관련 권리의 기록이며 ElevenLabs의 출력물 학습 이용 허용 계약까지 확인되었다는 뜻인지는 알 수 없다. **적용 계약에 명시적인 허용이 있는지 확인하기 전까지 해당 녹음을 새 학습에 사용하거나 학습 결과를 배포하지 않는다.** API 추가 사용은 사용자의 별도 지시가 필요하다.

## 권장 시험 순서

1. 학습 데이터의 화자·출처·학습 및 서비스 이용 조건을 확인하고, 좋아하는 대화체 음성을 듣는다.
2. Qwen Base 공식 경로 또는 LFM3의 확인된 학습 경로로 작게 시험한다. 맥미니 16GB에서 학습 가능한지, 추가 GPU가 필요한지는 아직 미확인이다.
3. C·D의 기존 문장과 학습에 넣지 않은 새 문장을 사용해 학습 전후 및 H2-D를 같은 조건으로 비교한다.
4. 발음·숫자와 날짜 정확도·억양 자연스러움·목소리 유사도·문장 간 일관성·첫 소리까지 시간을 따로 기록한다. 합성 음성의 STT 되받아쓰기는 보조 지표로 쓰고 직접 청취를 병행한다.
5. LFM3를 TTS 학습할 경우 같은 모델의 STT 정확도와 속도도 학습 전후 비교한다. 학습과 평가에 같은 문장을 섞지 않는다.
