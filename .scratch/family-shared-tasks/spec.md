## 설계

| 항목 | 정한 것 |
|---|---|
| 공유 기록 | 서버 메모리에 둔다. 폰 두 대가 같은 서버를 쓰면 한쪽에서 바꾼 것을 다른 쪽에서 바로 본다. 서버를 다시 켜거나 `POST /demo/reset`을 부르면 처음 시험 데이터로 돌아간다. 동시 요청은 잠금으로 막는다. |
| 누가 했는지 | 문장 속 **남편·아내**로 알아듣는다(2026-11-05 14:20부터 앱의 '나' 고르기 없앰). "아내가 냈어" → 아내, "남편한테 ~ 부탁해줘" → 아내가 남편에게. 사람이 없이 "내가"·"나한테"면 기본 사람(아내, `/ask`의 `speaker` 기본값). |
| 완료 알리기 | 기록을 바꾸는 말은 **사람 + 지난 일**("가스비 아내가 냈어") 또는 **"…했다고 체크해줘"**·"내가 …했어". 사람이 없는 "가스비 냈어?"와 물음표로 끝나는 "남편이 냈어?"는 묻는 말이다. |
| 글자 비교 | 기존 `compact_question`(NFC, 글자·숫자만)으로 비교한다. 물건 이름·부탁 내용·장소를 뽑을 때는 문장부호와 특수 공백을 일반 공백으로 바꾼 글을 쓴다. |
| 금액 | STT가 숫자로 적은 형태만 처리한다(`8만 4천 원`, `84,000원`, `8만원`). 한글 수사(`팔만 사천 원`)는 처리하지 않는다. 화면 글은 `4만 2천 원` 꼴이고, 읽기 변환이 "사만 이천 원"으로 읽는다. |
| 날짜 | 서버의 한국 시각 기준이다. 시험 데이터는 2026년 11월 기준이다. |

## STT 보정 (`server/app/stt_correction.py`, 2026-11-05 추가)

질문을 비교하기 전에 한 번 거친다(C·D 모두). 정해진 목록만 바꾸고, 비슷한 글자를 추측하지 않는다. 바뀌면 서버 로그에 `ask corrected '전' -> '후'`가 찍힌다.

| 종류 | 목록 |
|---|---|
| 동의어 → 표준 말 | 와이프→아내, 신랑→남편, (시)어머님→시어머니, 장모(님)·친정어머니→친정엄마, 분리배출→분리수거, 가스요금→가스비, 핸드폰·휴대폰·통신요금→통신비, 예방주사·예방접종→백신 |
| 이름 목록 (뒤에 조사가 올 때만) | 소연·서윤→소윤, 브루펜·부루펜·부르팬·브루팬→부르펜 |
| 한글 금액 → 숫자 | 팔만 사천 원→84000원, 만 원→10000원. 단위(십·백·천·만·억)가 없는 말(예: '구원')과 숫자 바로 뒤('8만4천원')는 그대로 둔다 |

## 경계·실패 (자동 테스트)

- 목록에 없는 물건을 샀다고 하면 목록을 바꾸지 않는다. "장보기"가 들어 있으면 "목록에서 못 찾았어요"라고 안내한다.
- 금액 없이 "썼어"라고 하면 금액을 다시 묻는다.
- 요일 없이 하원 당번을 바꾸려 하면 요일을 다시 묻는다.
- 주말 하원을 물으면 "어린이집이 쉬어요"라고 답한다.
- 받을 부탁이 없으면 "온 부탁이 없어요"라고 답한다.
- 자기 자신에게 부탁하면 거절한다.
- 준비된 날이 아닌 준비물을 물으면 준비된 날짜를 안내한다.
- `speaker`가 잘못된 값이면 422로 거절한다.
- 초기화하면 시험 데이터가 처음으로 돌아간다.
- 기존 C1~C7은 그대로 동작한다.
